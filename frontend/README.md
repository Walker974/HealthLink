# HealthLink frontend

React + TypeScript + Vite PWA with a feature-based structure and shadcn/ui components.

From this folder:

```powershell
npm ci
npm run dev
npm run test
npm run build
```

Use http://localhost:5173 for Keycloak integration. Add `?preview=1` for the explicitly labelled maquette-based sample screens. Live routes use the Spring Boot API through `/api`.

See [the frontend guide](../docs/frontend.md) for the complete structure, Docker setup, API generation, current backend capabilities, offline behavior and preview controls.
